# Rust Bindings for Open-Meteo OmFileFormatC library

> **Note**: This repository is archived. The functionality has been migrated to: https://github.com/open-meteo/om-file-format/tree/main/rust/om-file-format-sys

This project provides bindings to the [OmFileFormat](https://github.com/open-meteo/om-file-format) library.

## Development

Build and Test:

```bash
git submodule update --init
cargo build
cargo test
```
